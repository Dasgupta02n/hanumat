## Week 1 — Search (point 1)

Google and AI search will not rank you until you **claim** the site.

### 1. Google Search Console

1. Open [https://search.google.com/search-console](https://search.google.com/search-console) with the Google account that should own Hanumat.
2. **Add property** → URL prefix → `https://hanumat.life`
3. Verify. Easiest if the domain DNS is already in that Google account (Domain verification). Otherwise HTML file upload to the VPS `html` folder — ask if you need that file placed.
4. After verified: **Sitemaps** → submit:

   `https://hanumat.life/sitemap.xml`

5. **URL inspection** → paste:

   `https://hanumat.life/en/path/hanuman-chalisa/`

   Request indexing. Repeat for Lingashtakam and Kalika Ashtakam.

6. Optional: Bing Webmaster Tools → same sitemap.

**Done when:** Search Console shows the sitemap as “Success” and Chalisa is “URL is on Google” (can take days).

### 2. Check the pages Google will see

Open in a private window:

- Chalisa title should mention **meaning** and **IAST**.
- Path page should list **Jump to a verse**.
- Footer: Trust · For temples.

If a phone still shows Hindi first: hard-refresh, or uninstall the old PWA and Add to Home Screen again.

## Week 2–4 — temples, Bal Vihar, students (point 3)

The site cannot email people for you. You copy the letter.

### 1. Make a QR (5 minutes)

1. Open any QR generator you trust (phone camera apps often have one; or search “QR code generator”).
2. Encode: `https://hanumat.life/`
3. Save PNG. Print on A5/A4 with this text under it:

```
Hanumat — free digital mandir
Hanuman · Shiva · Maa Kali
Read along after aarti. No ads.
hanumat.life
```

4. Put it in **one** place first: your home mandir, then a local Hanuman temple notice board (ask the pujari).

The same instructions are on https://hanumat.life/en/for-temples/

### 2. Email 10 places (not 200)

Make a list of 10:

- Local Hanuman / Shiva / Kali temples
- One Bal Vihar / Chinmaya / weekend Hindi school
- One university Hindu student association (HSA / HSC) if you know a student

Open https://hanumat.life/en/for-temples/ → copy the English or Hindi letter.

Send from `hello@hanumat.life` if you can (or your Gmail, and mention hanumat.life).

**Subject:** `Free Path Studio for your mandir (hanumat.life)`

Attach the QR PNG. Do not attach a pitch deck. Do not ask for money.

### 3. If a temple says yes

- QR in courtyard / prasad hall is enough.
- Offer the print path: Path Studio → **Print / PDF** (A4, no ads).
- You are **not** selling puja.

## Week 3+ — YouTube (point 4)

Hanumat does not upload video. You (or a niece/nephew with a phone) film three shorts.

Scripts: https://hanumat.life/en/media-kit/

### How to film a Tuesday 60-second

1. Phone vertical (9:16). Quiet room. One diya if you want.
2. Open Chalisa on a second device or print one chaupai.
3. **0–8s:** Devanagari on screen (or speak it slowly).
4. **8–20s:** same line in IAST (Roman).
5. **20–40s:** one sentence English meaning. No miracle claims.
6. **40–55s:** “Open Path Studio — free, no ads.”
7. **Last frame (end card), hold 5s:**

```
hanumat.life/en/path/hanuman-chalisa/
Free seva · not classical pāṭh
```

8. Thumbnail: one picture from the 108 gallery (Hanumat → 108 Images). Not a stock screaming Hanuman jpeg.
9. Upload to YouTube as **Short**. Title example:

   `Hanuman Chalisa meaning in English | one chaupai | hanumat.life`

10. Description: paste the same URL. First comment: Hindi URL for family.

Repeat Mondays with Lingashtakam, Amavasya with Kalika Ashtakam (reverent stills only — no sensational Kali).

**Never say** the site audio is temple pāṭh. Say “follow the text.”

Show people this once. They will not hunt an app store.

1. Open https://hanumat.life/en/path/hanuman-chalisa/

3. Then download the Chalisa pack as above.
