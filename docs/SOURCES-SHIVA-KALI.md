# Shiva & Kali path sources (v1)

All new texts were collated from **at least two independent public recensions**. Meanings are provisional plain language, not scholarly ṭīkā. Edition pins are stored on each `meta.json`.

## Shiva

| Path | Primary | Cross-check |
|------|---------|-------------|
| Mahamrityunjaya | Rigveda 7.59.12; TS 1.8.6; VS 3.60 | Wikipedia *Mahamrityunjaya Mantra*; standard Devanagari recensions. ॐ is liturgical prefix. |
| Panchakshara | Śatarudrīya / smārta japa `namaḥ śivāya` | Pan-Śaiva practice; five akṣaras stable. |
| Lingashtakam | Sanskrit Documents `lingashh` (Srinivas Sunder) | Green Message lingashtakam. Variant: भाषित/भासित in v1; विनाशन/विनाशित in v7. |
| Shiva Panchakshara Stotram | Green Message; Sringeri Sharada Peetham | Wikipedia hymn text. v2 मुख्य vs पुष्प; v5 यज्ञ vs यक्ष. |
| Rudrashtakam | Tulsidas, Ramcharitmanas Uttarakanda | Multiple Devanagari printings (BhajanSangam, sanatan-dharm, stotra.in). |
| Nirvana Shatkam | Green Message (Adi Shankara) | Standard Advaita Ātmaṣaṭkam recension. |
| Kalabhairava Ashtakam | Green Message (Adi Shankara) | Refrain काशिकापुराधिनाथकालभैरवं भजे stable. |
| Shiv Aarti | Temple booklet recension *Jai Shiv Omkara* | Line-order varies by region (same class of variance as Hanuman aarti). |

## Kali

| Path | Primary | Cross-check |
|------|---------|-------------|
| Dakshina Kali nama-mantra | Public japa `oṃ krīṃ kālikāyai namaḥ` | Woodroffe *Karpuradi-stotra* discusses the 22-syllable mūlamantra as tantric uddhāra — **not** published here as household recitation. Kali Gayatri from standard recensions. |
| Kalika Ashtakam | Green Message (attributed Adi Shankara) | Dhyana 1–3 + stuti 1–8; fierce traditional iconography retained in mula. |
| Adya Stotram | Sanskrit Documents `AdyA` (Mukherjee / Hattangadi); Brahma Yamala | Green Message; Adyapeath translation PDF. |
| Kali Aarti | Temple recension *Jai Kali Mata* | Regional line-order variants exist. |

## Not included (deliberate)

- Full *Karpuradi Stotram* (Mahakala) — authentic but a Kaula paddhati with cremation-ground sādhana; unsuitable as a household Path Studio text.
- Unverified Kali Chalisa variants (wide textual drift).
